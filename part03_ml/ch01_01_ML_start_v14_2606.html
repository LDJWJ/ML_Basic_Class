기본 개념 이해하기 데이터, 샘플, 특성 — 머신러닝의 언어
📖 핵심 용어

데이터의 두 축: 행(Row)과 열(Column)

  • 샘플(Sample) / 데이터 포인트(Data Point) — 하나의 개체 또는 관측치. 테이블의 행(row)에 해당합니다. 예: 붓꽃 한 송이의 측정값
  • 특성(Feature) / 속성(Attribute) — 샘플의 개별 속성. 테이블의 열(column)에 해당합니다. 예: 꽃잎 길이, 꽃받침 너비
  • 레이블(Label) / 타깃(Target) — 예측하고자 하는 값. 지도 학습에서 정답 역할을 합니다. 예: 붓꽃의 종류(setosa / versicolor / virginica)
💡 기억 방법

엑셀 스프레드시트를 떠올리세요. 가로 한 줄 = 샘플, 세로 한 열 = 특성. 머신러닝은 이 표에서 패턴을 찾는 작업입니다.

용어 (한국어) 용어 (영어) 엑셀 비유 붓꽃 예시
샘플 / 관측치 Sample / Data point 행(Row) 붓꽃 1송이 측정 결과
특성 / 속성 Feature / Attribute 열(Column) 꽃잎 길이, 꽃받침 너비 등
타깃 / 레이블 Target / Label 정답 열 품종(setosa, versicolor…)
특성 행렬 Feature Matrix (X) 정답 열 제외 전체 shape = (150, 4)
타깃 벡터 Target Vector (y) 정답 열만 shape = (150,)

✅ 왜 버전 확인이 중요한가?

API가 버전마다 다를 수 있으며, 팀 협업·재현성(reproducibility) 확보를 위해 환경을 명시해야 합니다. 오류 발생 시 버전 정보는 디버깅의 첫 단서가 됩니다.

붓꽃(Iris) 데이터셋 이해하기 머신러닝 입문의 고전 데이터셋
🌸 데이터 소개

붓꽃(Iris) 데이터셋

1936년 Ronald Fisher가 소개한 다변량 데이터셋. 세 종류의 붓꽃 각 50개씩 총 150개 샘플과 4개 특성으로 구성됩니다. 분류 알고리즘 학습의 표준 예제입니다.

📐 특성(Feature) 4개
sepal length (cm)꽃받침 길이
sepal width (cm)꽃받침 너비
petal length (cm)꽃잎 길이
petal width (cm)꽃잎 너비
🏷️ 타깃(Target) 3종
0Iris setosa (부채붓꽃)
1Iris versicolor (버시컬러)
2Iris virginica (버지니카)
Python — 붓꽃 데이터 로드 및 탐색
from sklearn.datasets import load_iris import pandas as pd # 데이터 로드 iris = load_iris() # 기본 정보 확인 print("특성 이름 :", iris.feature_names) print("타깃 이름 :", iris.target_names) print("X 형태 :", iris.data.shape) # (150, 4) print("y 형태 :", iris.target.shape) # (150,) # DataFrame으로 변환하여 확인 df = pd.DataFrame(iris.data, columns=iris.feature_names) df['target'] = iris.target print(df.head()) print(df.describe())
💡 탐색적 데이터 분석 (EDA) 팁
  • df.info() — 데이터 타입 및 결측값 여부 확인
  • df.describe() — 통계 요약 (평균, 표준편차, 최솟값, 최댓값)
  • df.isnull().sum() — 결측값 개수 확인
  • df['target'].value_counts() — 클래스 분포 확인

첫 번째 ML 모델 만들기 k-최근접 이웃(KNN) 분류기로 붓꽃 분류
scikit-learn 모델 개발 4단계
① 데이터 준비
X, y 분리
→
② 데이터 분할
train / test
→
③ 모델 학습
.fit()
→
④ 예측·평가
.predict() / score()
Python — KNN 분류 모델 전체 코드
from sklearn.datasets import load_iris from sklearn.model_selection import train_test_split from sklearn.neighbors import KNeighborsClassifier from sklearn.metrics import accuracy_score, classification_report # ① 데이터 준비 iris = load_iris() X, y = iris.data, iris.target # ② 학습/테스트 데이터 분할 (75% / 25%) X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.25, random_state=42 ) print(f"학습 데이터: {X_train.shape}, 테스트 데이터: {X_test.shape}") # ③ 모델 생성 및 학습 model = KNeighborsClassifier(n_neighbors=3) model.fit(X_train, y_train) # ④ 예측 및 평가 y_pred = model.predict(X_test) accuracy = accuracy_score(y_test, y_pred) print(f"정확도 (Accuracy): {accuracy:.4f}") print("\n분류 리포트:") print(classification_report(y_test, y_pred, target_names=iris.target_names)) # 출력 예시 # 학습 데이터: (112, 4), 테스트 데이터: (38, 4) # 정확도 (Accuracy): 1.0000
📝 코드 해설
  • train_test_split — 데이터를 학습용/테스트용으로 분리. random_state로 재현성 확보
  • KNeighborsClassifier — k개의 가장 가까운 이웃을 보고 다수결로 분류
  • .fit() — 모델 학습 (학습 데이터로만)
  • .predict() — 새 데이터 예측 (테스트 데이터)
  • accuracy_score — 정확도 계산 = 맞힌 수 / 전체 수
⚠️ 흔한 실수
  • 테스트 데이터로 학습하는 데이터 누수(Data Leakage)
  • random_state를 설정하지 않아 실행마다 결과가 달라지는 경우
  • 정확도(Accuracy)만 보고 클래스 불균형을 간과하는 경우
  • X_test로 fit()을 호출하는 실수

현대적 MLOps 워크플로우 알고리즘 적용을 넘어 파이프라인 전체를 바라보기
📌 MLOps란?

ML(머신러닝) + Ops(운영)의 합성어. 머신러닝 모델을 프로덕션 환경에서 안정적으로 개발·배포·모니터링하기 위한 실천 원칙과 도구 체계입니다.

  1. 문제 정의 및 데이터 수집

    해결할 비즈니스 문제를 ML 문제로 변환. 필요한 데이터의 종류·규모·출처를 정의하고 수집합니다.

  2. 탐색적 데이터 분석(EDA)과 특성 엔지니어링

    데이터 분포 파악, 이상치·결측값 처리, 새로운 특성 생성. 모델 품질의 80%는 데이터 전처리에서 결정됩니다.

  3. 모델 개발 및 실험 관리

    여러 알고리즘 비교, 하이퍼파라미터 튜닝, 교차 검증. MLflow나 Weights&Biases로 실험 이력을 기록합니다.

  4. 모델 평가 및 해석

    정확도·정밀도·재현율·F1·AUC 등 다양한 지표로 평가. SHAP·LIME으로 모델 예측 근거를 설명합니다.

  5. 모델 배포 및 서빙

    REST API(Flask, FastAPI), Docker 컨테이너화, 클라우드 배포(AWS SageMaker, GCP Vertex AI 등).

  6. 지속적 모니터링 및 재학습

    데이터 드리프트(Data Drift)·개념 드리프트(Concept Drift) 감지. 성능 저하 시 자동 재학습 파이프라인 구동.

💡 지금 단계에서는

지금은 1~4단계에 집중합니다. 배포와 모니터링은 모델을 충분히 이해한 후 학습합니다. 단, 처음부터 실험 관리를 습관화하면 나중에 큰 자산이 됩니다.

Python — n_neighbors 파라미터 실험 (과제 4)
from sklearn.datasets import load_iris from sklearn.model_selection import train_test_split from sklearn.neighbors import KNeighborsClassifier iris = load_iris() X_train, X_test, y_train, y_test = train_test_split( iris.data, iris.target, test_size=0.25, random_state=42 ) print("k값 | 정확도") print("-" * 20) for k in [1, 3, 5, 7, 9, 11]: model = KNeighborsClassifier(n_neighbors=k) model.fit(X_train, y_train) score = model.score(X_test, y_test) print(f" k={k:2d} | {score:.4f}")
