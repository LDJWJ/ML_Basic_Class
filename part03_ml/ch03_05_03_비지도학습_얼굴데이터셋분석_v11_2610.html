최신 scikit-learn은 pca.inverse_transform()에 1차원 배열(중심점 하나)을 넣으면 에러를 내요. center.reshape(1, -1)로 2차원으로 바꿔 넣고, 같은 호출을 내부에서 하는 mglearn.plots.plot_kmeans_faces에는 2차원으로 바꿔 주는 작은 껍데기(PCA2D)를 넘기도록 했습니다. KMeans는 scikit-learn 1.4부터 기본 시도 횟수가 줄어서 n_init=10을 적어 예전과 같은 방식으로 돌렸어요.

mask = np.zeros(people.target.shape, dtype=np.bool)
for target in np.unique(people.target):
    mask[np.where(people.target == target)[0][:50]] = 1
    
X_people = people.data[mask]
y_people = people.target[mask]

# 0~255 사이의 흑백 이미지의 픽셀 값을 0~1 사이로 스케일 조정합니다.
# (옮긴이) MinMaxScaler를 적용하는 것과 거의 동일합니다.
X_people = X_people / 255.

k-평균으로 얼굴 데이터 분석¶

  • DBSCAN에서는 하나의 큰 클러스터 외에는 만들 수 없음.
  • 병합군집과 K-means은 비슷한 크기의 클러스터를 만들 수 있음.

km = KMeans(n_clusters=10, random_state=0, n_init=10)  # 2026.10 수정: scikit-learn 1.4부터 n_init 기본값이 10→'auto'(1번)로 바뀌어 예전처럼 10번 시도
labels_km = km.fit_predict(X_pca)

# 2026.10 수정: mglearn 내부가 pca.inverse_transform(1차원 배열)을 호출하는데, 최신 scikit-learn은 2차원만 받음 → 2차원으로 바꿔 주는 껍데기로 감싸서 전달
class PCA2D:
    def __init__(self, pca): self.pca = pca
    def inverse_transform(self, X): return self.pca.inverse_transform(np.atleast_2d(X))

mglearn.plots.plot_kmeans_faces(km, PCA2D(pca), X_pca, X_people,
                                y_people, people.target_names)
  • 두번째 클러스터가 웃는 얼굴.
  • 나머지 클러스터는 얼굴 각도 중시
