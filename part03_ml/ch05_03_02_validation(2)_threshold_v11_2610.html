# 2026.10 수정: 예전 mglearn의 make_blobs는 n_samples=(400, 50)처럼 클래스별 개수와 centers=2를 같이 받았는데,
# mglearn 0.2.0부터는 sklearn의 make_blobs를 그대로 써서 이 조합이 ValueError가 납니다.
# 예전과 똑같은 데이터가 나오도록 예전 mglearn 방식을 그대로 옮긴 함수입니다.
import numpy as np

def make_blobs(n_samples, centers=2, cluster_std=1.0, random_state=None,
               n_features=2, center_box=(-10.0, 10.0)):
    rng = np.random.RandomState(random_state)
    centers = rng.uniform(center_box[0], center_box[1], size=(centers, n_features))  # 중심점을 무작위로
    X, y = [], []
    for i, (n, std) in enumerate(zip(n_samples, cluster_std)):
        X.append(centers[i] + rng.normal(scale=std, size=(n, n_features)))  # 중심점 주변에 n개
        y += [i] * n
    X, y = np.concatenate(X), np.array(y)
    idx = np.arange(len(y))
    rng.shuffle(idx)  # 클래스 순서를 섞기
    return X[idx], y[idx]

임계값을 낮추는 것은¶

  • 정밀도(precision) 0.42에서 0.33로 낮아지고
  • 재현율(recall)-sensitivity(민감도)는 0.83에서 1로 올라감.
  • 결론적으로 1(양성)의 수가 늘어나기 때문에 TP(진짜 양성)의 개수가 늘어난다.
  • TP, FP를 함께 늘려주기 때문에 정밀도는 낮아진다.
  • TP, FP가 늘어나지만, 상대적으로 FN이 줄어들기에, 이에 관련된 민감도의 값을 높아지게 된다.

Review¶

  • 정밀도(precision)
    • TP/(TP + FP) : 예측 양성 전체 중에 정확하게 잘 맞추었을까?
  • 민감도 or 재현율(recall) :

    • TP/(TP + FN) : 실제 양성 데이터의 얼마나 잘 맞추었을까?

    • 다른 말로 **민감도(sensitivity), 적중률(hit rate), 진짜 양성 비율(TPR)**이라고 합니다.

  • F1-score \begin{equation} \text{F} = 2 * \frac{\text{정밀도*재현율}}{ \text{정밀도 + 재현율 } } \end{equation}

실습¶

  • 임계값을 0보다 큰 값으로 조정해 보고 재현율(recall)를 확인해 보기
  • 임계값을 0으로 하고 재현율(recall)과 기타 평가지표를 확인해 보기

    • 임계값을 높이는 것은 양성이 분류될 확률이 많이 나올 때, 수행
