3 TF-IDF 벡터 계산 ▶
TF: 각 토큰이 문서 내에서 등장한 빈도 (정규화)
IDF: log(전체 문서 수 / 해당 토큰이 등장한 문서 수)
TF-IDF = TF × IDF — 자주 나오지만 모든 문서에 등장하는 단어의 가중치를 낮춥니다.
const tfidfVectors = docsTokens.map(tokens => { const tf = new Array(vocabList.length).fill(0); tokens.forEach(token => { const idx = vocabIndex[token]; tf[idx] += 1; // 단어 빈도 증가 }); const tokenCount = tokens.length; const tfidf = tf.map((count, idx) => { const tfVal = tokenCount ? count / tokenCount : 0; return tfVal * idf[idx]; // TF × IDF }); return tfidf; });

4 코사인 유사도 계산 ▶
두 벡터 사이의 코사인 유사도를 계산합니다.
cos(θ) = (A · B) / (||A|| × ||B||) — 값이 1에 가까울수록 유사한 문서입니다.
function cosineSimilarity(vecA, vecB) { let dot = 0, normA = 0, normB = 0; for (let i = 0; i < vecA.length; i++) { dot += vecA[i] * vecB[i]; // 내적 normA += vecA[i] * vecA[i]; // A의 제곱합 normB += vecB[i] * vecB[i]; // B의 제곱합 } if (normA === 0 || normB === 0) return 0; return dot / (Math.sqrt(normA) * Math.sqrt(normB)); }

5 추천 결과 정렬 ▶
자기 자신을 제외하고, 유사도 점수가 높은 순서대로 정렬하여 상위 3개를 추천 결과로 반환합니다.
function recommend(movieIndex, topN = 3) { const baseVector = tfidfVectors[movieIndex]; const scores = tfidfVectors.map((vec, idx) => ({ index: idx, score: cosineSimilarity(baseVector, vec) })); return scores .filter(item => item.index !== movieIndex) // 자기 자신 제외 .sort((a, b) => b.score - a.score) // 유사도 내림차순 .slice(0, topN); // 상위 3개 }
