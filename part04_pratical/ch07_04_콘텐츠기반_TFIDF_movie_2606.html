개념 한 줄 설명 예시
TF (Term Frequency) 한 문서에서 단어가 얼마나 자주 나오는가 "액션"이 3번 → TF 높음
IDF (Inverse Document Frequency) 전체 문서에서 희귀할수록 정보량이 큼 "마블"은 일부 영화에만 → IDF 높음
TF-IDF 두 값의 곱. 중요한 단어에 높은 가중치 TF × IDF = 벡터값
코사인 유사도 두 벡터가 이루는 각도의 코사인 값 (0~1) 1에 가까울수록 유사한 영화
💡 직관적 이해

"어벤져스"와 "아이언맨"은 둘 다 슈퍼히어로, 마블, 액션 키워드를 공유합니다. TF-IDF는 이 단어들에 높은 점수를 주고, 코사인 유사도는 두 벡터가 비슷한 방향을 가리킨다는 것을 수치로 확인해줍니다.

2

데이터 준비

⏱ 10분
📖 왜 키워드 형식인가?

TF-IDF는 단어 빈도를 기반으로 합니다. 문장보다는 명사/형용사 키워드를 공백으로 구분한 형태가 유사도 계산에 더 효과적입니다. 자연어 문장은 조사·접속사 등 노이즈가 많아 결과가 부정확해질 수 있습니다.

python Step 1 — 예제 데이터 만들기 
import pandas as pd

# 영화 데이터: 제목 + 키워드 설명
movies = pd.DataFrame({
    "title": [
        "어벤져스", "아이언맨", "노트북", "라라랜드",
        "인셉션", "인터스텔라", "겨울왕국", "토이스토리"
    ],
    "description": [
        "슈퍼히어로 액션 전투 마블",
        "슈퍼히어로 과학 기술 액션 마블",
        "로맨스 사랑 감동 드라마",
        "음악 로맨스 꿈 사랑",
        "꿈 현실 SF 액션 스릴러",
        "우주 시간 SF 감동 과학",
        "애니메이션 음악 가족 마법",
        "애니메이션 장난감 가족 모험"
    ]
})

print(movies)

  • movies.shape → (8, 2) 출력 확인
  • movies.head() → 데이터프레임 미리보기
  • 키워드가 공백으로 구분된 문자열 형식인지 확인

3

TF-IDF 벡터화

⏱ 15분
📖 fit_transform이 하는 일
  • fit: 전체 문서에서 단어 사전(vocabulary) 구축 + IDF 계산
  • transform: 각 문서를 TF-IDF 가중치 벡터로 변환
  • 결과는 영화 수 × 전체 단어 수 크기의 희소 행렬(sparse matrix)
python Step 2 — 텍스트를 TF-IDF 벡터로 변환 
from sklearn.feature_extraction.text import TfidfVectorizer

# 벡터라이저 생성 및 학습+변환
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(movies["description"])

# 행렬 크기 확인: (영화 수, 고유 단어 수)
print(f"행렬 크기: {tfidf_matrix.shape}")

# 단어 목록 확인
print("단어 사전:", vectorizer.get_feature_names_out())

# 밀집 행렬로 변환해서 직접 확인 (학습용)
import pandas as pd
tfidf_df = pd.DataFrame(
    tfidf_matrix.toarray(),
    index=movies["title"],
    columns=vectorizer.get_feature_names_out()
)
print(tfidf_df.round(2))
🔍 출력 해석 실습
  • "마블" 열을 보면 어벤져스·아이언맨만 값이 있고 나머지는 0
  • "음악" 열을 보면 라라랜드·겨울왕국에만 값이 있음
  • 같은 키워드를 공유할수록 벡터가 비슷한 방향을 가리킴

코사인 유사도 계산

⏱ 10분
📖 코사인 유사도란?

두 벡터 간의 각도의 코사인 값으로 유사도를 측정합니다. 벡터의 크기(길이)가 달라도 방향이 같으면 1에 가까운 값을 얻습니다. 텍스트 길이가 다른 문서 비교에 적합합니다.


• 값 = 1.0 → 완전히 동일한 방향 (같은 영화)

• 값 = 0.5~0.9 → 유사한 영화

• 값 ≈ 0.0 → 완전히 다른 장르

python Step 3 — 영화 간 코사인 유사도 행렬 생성 
from sklearn.metrics.pairwise import cosine_similarity

# (8 x 8) 유사도 행렬 — 모든 영화 쌍의 유사도
similarity = cosine_similarity(tfidf_matrix, tfidf_matrix)

# 데이터프레임으로 보기 좋게 출력
sim_df = pd.DataFrame(
    similarity,
    index=movies["title"],
    columns=movies["title"]
)
print(sim_df.round(2))
🔍 유사도 행렬 읽는 법
  • 대각선(자기 자신과의 유사도)은 항상 1.0
  • 어벤져스-아이언맨 셀 값이 가장 높을 것으로 예상 → 확인해 보세요
  • 어벤져스-노트북 셀은 거의 0에 가까울 것 → 왜 그럴까요?
⚠ 주의: 대칭 행렬

유사도 행렬은 항상 대칭입니다. A→B 유사도와 B→A 유사도는 동일합니다. 따라서 실제 서비스에서는 절반만 계산해 메모리를 아끼는 최적화를 사용합니다.

추천 함수 구현 및 실행

⏱ 15분
python Step 4 — 추천 함수 정의 
def recommend_movie(movie_title, top_n=3):
    """
    특정 영화와 가장 유사한 영화를 top_n개 추천
    """
    # ① 입력 영화의 인덱스 찾기
    movie_index = movies[movies["title"] == movie_title].index[0]

    # ② 해당 영화와 모든 영화의 유사도 가져오기
    scores = list(enumerate(similarity[movie_index]))

    # ③ 자기 자신 제외, 유사도 높은 순 정렬
    scores = sorted(scores, key=lambda x: x[1], reverse=True)
    scores = scores[1:top_n + 1]  # 0번째(자기 자신) 제외

    # ④ 결과 출력
    print(f"\n🎬 '{movie_title}'를 좋아한다면:")
    for rank, (idx, score) in enumerate(scores, 1):
        print(f"  {rank}위. {movies.iloc[idx]['title']}  (유사도: {score:.2f})")

# ── 실행 ──
recommend_movie("어벤져스", top_n=3)
recommend_movie("라라랜드", top_n=3)
recommend_movie("인터스텔라", top_n=3)
📖 코드 흐름 분해
  • ① movies["title"] == movie_title → 불리언 마스크로 인덱스 추출
  • ② enumerate(similarity[movie_index]) → (인덱스, 유사도) 쌍의 리스트
  • ③ sorted(..., reverse=True) → 내림차순 정렬 후 자기 자신 제외
  • ④ movies.iloc[idx] → 인덱스로 영화 정보 조회
✅ 예상 출력 확인 체크리스트
  • "어벤져스" → 아이언맨(마블/액션 공유)이 1위로 나오는가?
  • "라라랜드" → 노트북 또는 겨울왕국(음악/사랑)이 상위에 나오는가?
  • "인터스텔라" → 인셉션(SF 공유)이 상위에 나오는가?
  • 유사도 점수가 0.0~1.0 범위에 있는가?

전체 코드 (한 번에 실행)

python 완성 코드 — 복사해서 바로 실행 가능 
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# 1. 예제 영화 데이터 만들기
movies = pd.DataFrame({
    "title": [
        "어벤져스", "아이언맨", "노트북", "라라랜드",
        "인셉션", "인터스텔라", "겨울왕국", "토이스토리"
    ],
    "description": [
        "슈퍼히어로 액션 전투 마블",
        "슈퍼히어로 과학 기술 액션 마블",
        "로맨스 사랑 감동 드라마",
        "음악 로맨스 꿈 사랑",
        "꿈 현실 SF 액션 스릴러",
        "우주 시간 SF 감동 과학",
        "애니메이션 음악 가족 마법",
        "애니메이션 장난감 가족 모험"
    ]
})

# 2. 영화 설명을 숫자 벡터로 변환
vectorizer = TfidfVectorizer()
tfidf_matrix = vectorizer.fit_transform(movies["description"])

# 3. 영화끼리 유사도 계산
similarity = cosine_similarity(tfidf_matrix, tfidf_matrix)

# 4. 추천 함수 만들기
def recommend_movie(movie_title, top_n=3):
    movie_index = movies[movies["title"] == movie_title].index[0]
    scores = list(enumerate(similarity[movie_index]))
    scores = sorted(scores, key=lambda x: x[1], reverse=True)
    scores = scores[1:top_n + 1]
    print(f"\n🎬 '{movie_title}'를 좋아한다면:")
    for rank, (idx, score) in enumerate(scores, 1):
        print(f"  {rank}위. {movies.iloc[idx]['title']}  (유사도: {score:.2f})")

# 5. 실행
recommend_movie("어벤져스", top_n=3)
recommend_movie("라라랜드", top_n=3)
recommend_movie("인터스텔라", top_n=3)
